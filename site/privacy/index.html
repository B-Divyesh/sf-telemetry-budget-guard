Privacy, without fine print.

Telemetry Budget Guard is local-first. The CLI reads files you choose, aggregates them in process, and does not transmit or persist their contents. Sensitive body and prompt-like fields are excluded by default.

Website

The browser demo runs entirely in your browser. Pasted data is not uploaded, saved to local storage, or sent to analytics. This static site does not use cookies, tracking pixels, third-party scripts, or third-party fonts.

CLI

The CLI has no telemetry and makes no network requests. `--allow-sensitive` changes only the in-memory estimate for that invocation.

Contact

Questions and security reports can be opened on the project issue tracker.
