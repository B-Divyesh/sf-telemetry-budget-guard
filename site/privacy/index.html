Understand how your telemetry is handled

The check command reads only the files you name. It aggregates their contents in the running process.

CLI data

The check command creates no output files and makes no network requests. Reports go to standard output.

Body fields and attribute keys containing prompt, body, content, message, or query are removed before aggregation by default.

The optional sensitive-field flag keeps those fields in memory for that command only.

Browser sample

The sample calculator runs in your browser. It does not upload input or write it to browser storage.

The service worker caches public site files for offline use. It does not cache text entered into the sample form.

Website requests

The site uses no analytics, cookies, tracking pixels, third-party scripts, or third-party fonts.
