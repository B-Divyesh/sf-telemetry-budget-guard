How it works

Compare the proposed Collector config in three steps

  1. 01

    Capture a bounded sample

    Use OTLP/HTTP JSON, a compact JSON array, or JSONL.

  2. 02

    Compare both configs

    Run the sample through baseline and proposed processor chains.

  3. 03

    Fail an over-budget change

    Set TOML limits. Read the report or stable JSON in CI.

Limits and privacy

Know what the estimate covers

Modeled
Attribute and resource actions, strict and regexp filters, probabilistic sampling, and duplicate pipelines.
Reported
Unsupported processors produce warnings and stay volume-neutral.
Protected
Body, prompt, content, message, and query fields are removed before aggregation by default.
Not included
This tool does not store traces, recommend vendors, or replace a production bill.
